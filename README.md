# Speech Partner.German

Een gratis, offline werkende app (PWA) om Duits te gebruiken in gesprekken. Geen account, geen server, geen kosten.

Deze map is een complete app. Zet de **inhoud** van deze map in een eigen GitHub-repository (bijvoorbeeld `speechpartner-german`) en zet GitHub Pages aan.
Gebruik niet de repository van de Spaanse app: elke taal heeft zijn eigen repository en zijn eigen webadres.

Versie 1.1
